# Payroll Operations Demo

A portfolio-safe demonstration of a configurable payroll operations workspace.

> **Demo only:** This repository uses entirely fictional people, company names, rates, transactions, and payment records. It is not connected to any employer, payroll provider, bank, CRM, or production system.

## What this demo illustrates

- People directory with fictional team members and roles
- Configurable compensation profiles and effective dates (illustrative only)
- Payroll period overview and sample calculations
- Commission traceability from an original sale to later collections
- Retention register and review states
- Exceptions, adjustments, and audit-history concepts
- Onboarding and offboarding checklists, including final-pay review
- Safe record lifecycle concepts: archive, void, reverse, and reactivate rather than permanent deletion

## Run locally

No installation is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

All content is static demonstration data. Actions are illustrative and do not submit payments or persist to a server.

## Project status

This is a front-end portfolio prototype, not production payroll software. Authentication, authorization, secure persistence, integrations, tax calculations, payment execution, and independent payroll validation are not implemented.

## Privacy and security

Do not add real employee data, compensation records, bank details, customer information, credentials, API keys, or employer-confidential policies to this public repository.
