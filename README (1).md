# SILO — Payroll Operations Platform (Portfolio Edition)

A broad front-end portfolio demonstration of a configurable payroll operations workspace.

## Modules demonstrated
- Dashboard with payroll KPIs, period selector and operational activity
- People directory and Coach / Closer / Setter team montages
- Individual profile concepts and compensation structures
- Effective-dated pay rules and approval controls
- Guided payroll review, exception handling and payment preparation
- Commission ledger, new-close attribution, recurring collections and clawbacks
- Retention register with assigned coach, payment structure and evidence
- Collection traceability from original sale to later instalments / continuation payments
- Issues and adjustments
- Onboarding, offboarding and final-pay reconciliation
- Audit trail, payment states, access controls and no-permanent-deletion principles

## Run locally
Open `index.html` in a modern browser. No installation is required.

## Limitations
This is a static front-end portfolio demonstration using fictional company, people, client, compensation and transaction data. Buttons and forms illustrate workflows but do not persist to a server or execute payroll. There is no authentication, backend database, secure persistence, provider integration, tax engine or payment execution.

## Privacy
Do not add real employer information, employee records, actual compensation arrangements, customer data, bank details, credentials, API keys or confidential policies to this public repository.
